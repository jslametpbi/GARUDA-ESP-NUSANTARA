# GARUDA ESP NUSANTARA

A static GitHub Pages-ready multi-role ESP platform.

- Student
- Lecturer (requires Admin approval)
- Admin

## Main Features
- One-fit exclusive landing page
- 16-week ESP studio
- 6 ESP disciplines
- 6 Garuda pathways per discipline
- Province-based Nusantara atlas (38 provinces)
- Online live-room hub (Zoom-style workflow)
- AI-assisted local tools
- Voice and pronunciation practice
- Tasks, submissions, review, analytics, and export

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Ensure `index.html` is in the root.
4. In GitHub, open **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**.
7. Click **Save**.
8. Wait until Pages finishes deployment.
9. Open the generated GitHub Pages URL.

# Garuda ESP Nusantara

Static GitHub Pages deploy-ready ESP application.

## Admin
Admin PIN: `JS2026`

## Deploy
Upload all extracted files to the root of a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

## Included
- Secure role access: Student, Lecturer, Admin
- Lecturer approval by Admin
- Users & institutions management and mapping
- 16-week semester ESP materials with reading, listening, speaking, writing, vocabulary/grammar, assessment, assignments, and resources
- Play, Stop, and Record controls
- Virtual classroom room management
- Forum, chat, help desk
- Analytics, reports, export, settings
